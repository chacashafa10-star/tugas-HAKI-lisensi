A. Identitas Produk Perangkat Lunak
1. Nama Aplikasi / Software: Teh Kataji (Teh Kataji berbasis web)
2. Kategori Produk: Aplikasi Kasir & Manajemen Stok UMKM Berbasis Android
3. Deskripsi Singkat Fungsi Aplikasi:
Teh Kataji adalah aplikasi penjualan online yang dirancang untuk membantu pedagang UMKM 
dalam pencatatan transaksi penjualan secara real-time, pencetakan dan manajemen stok barang 
berbasis cloud Supabase.
